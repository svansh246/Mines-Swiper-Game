## ✨ Features

- Modern graphical user interface
- Beginner, Intermediate, and Expert difficulty levels
- Custom board dimensions and mine counts
- Timer and remaining-mine counter
- Right-click flagging system
- Automatic reveal of adjacent safe cells
- First-click safety
- Win and loss detection
- Restart functionality

## 🛠️ Technologies Used

- Python 3
- Tkinter
- Random module
- Time module

## 🚀 How to Run

1. Install Python 3.
2. Clone this repository or download the project files.
3. Open a terminal in the project folder.
4. Run:

   `python minesweeper.py`

## 🎮 Controls

- Left-click: Reveal a cell
- Right-click: Place or remove a flag
- Restart: Start a new game
- Difficulty: Select your preferred level
